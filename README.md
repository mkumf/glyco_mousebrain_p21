# Overview

Repository for the project *Spatial O-GalNAc glycoproteomics reveals region-specific regulation across the mouse brain*, including scripts used for data pre-/processing and for geerating the central figures.

# Repo Contents

- [preprocessing](./preprocessing): `R`/`Delphi` scripts for data preprocessing, 
- [processing_plots](./docs): package documentation, and usage of the `lolR` package on many real and simulated data examples.
- [manual_glycodb](./man_glycodb): manual for the website associated with the paper, [GlycoDB.org](https://glycodb.org/).

# System Requirements

## Hardware Requirements

The analysis was done on a 2019 MacBook Pro  
RAM: 16 GB  
CPU: 2,4 GHz Quad-Core Intel Core i5

## Software Requirements

The `R` scripts were run using  

MacOS: Sequoia 15.7.9  
R: Version 4.5.3 (2026-03-11)  
RStudio: Version 2026.05.0+218

All packages and dependencies were installed from CRAN respectively Bioconductor (if available) or directly from GitHub using the respective instructions.
